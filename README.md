並且與「匯率換算」共用同一套判斷函式，會進一步拆成：

✅ 無任何使用條件，可優先考慮

只有「限制／適用通路」及「備註」皆為空白才會進入本區。

⚠️ 有限制／適用通路，符合條件時再考慮

只要存在支付方式、指定通路、實體／網路限制、權益切換、登錄、交通票卡等條件，就會進入此區，而且直接顯示實際限制內容。

如此像「台新 Richart 3.8% 無上限」這種實際上有「限定台新 Pay+」條件的方案，就不會再被誤認為無條件無腦刷。
